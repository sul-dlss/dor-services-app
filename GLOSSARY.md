# Glossary

**Virtual object**: An item whose structure is an ordered list of other items rather than its own files.

**Constituent**: An item listed in a virtual object's structure. An item is a *constituent of* every virtual object whose current (head) version lists it, including one with an open, not-yet-accessioned version.

**Current error**: A Process in error in the latest version of its workflow. It stops being current once the Process is retried, skipped or completed.

**Error date**: When an object's most recent current error happened. An object with no current errors has no error date.
